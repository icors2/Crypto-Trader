# Templates

Copy only what the project needs during bootstrap. Paths below are relative to `assets/templates/`.

| Path | Use |
| --- | --- |
| `SKILL.template.md` | New project skill skeleton |
| `rule.template.mdc` | New project rule skeleton |
| `decision.md` | ADR entry snippet |
| `AGENTS.project-section.md` | Shape for `AGENTS.md` Project-specific |
| `github/` | PR/issue templates, CODEOWNERS, Dependabot, SECURITY, CONTRIBUTING |
| `ci/` | GitHub Actions (Node, Python, security scan) |
| `config/` | EditorConfig, ESLint, Prettier, TS, Vitest, Ruff, pytest |
| `docker/` | Dockerfiles, `.dockerignore`, compose |
| `env/` | Cloud `environment.json` examples |
| `hooks/` | Optional Cursor hooks (not active until copied) |
| `legal/` | Privacy policy and terms templates (not legal advice) |
